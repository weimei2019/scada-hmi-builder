# 组态素材包导出（GLB / 图标 / SVG / 坐标 / 点位 / 状态版）

目的：把三维页拆成**第三方组态软件能直接用**的素材。仓库 `tools/pack/` 里有两套可当模板的实现（导出页 `export*.html` + 构建脚本 `build-pack*.mjs` + 打包脚本 `make-zips*.py` + `README*.md`）；新项目复制一套改名即可。

## 一、产出

| 目录 / 文件 | 内容 |
|---|---|
| `models/equipment/*.glb` | 每台设备一个 GLB，**按底面中心归零**；单台泵组 / 储罐 / 池体 / 压滤机 / 流量计 / 电动阀…各一个 |
| `models/parts/*.glb` | 通用小件（离心泵、搅拌机、阀门横 / 立、管道箭头…） |
| `models/pipes_all.glb` | 全部管线，每种介质一个材质（`pipe_<kind>`） |
| `models/plant_full.glb` | 整厂（设备 + 平台 + 管线，保持原位置） |
| `sprites/*.png` | 512 px 透明底 2.5D 图标 + `_overview.png` 整厂总览（2400 px） |
| `svg/page|iso|front|top/*.svg` | 4 个视角矢量图（`page` = 页面同款视角） |
| `layout.json` | 每台设备的世界坐标 / 尺寸 / 所属工段；管线折线点（管径、介质）；三维标签；泵编号 |
| `tags.csv` / `tags.json` | 点位清单（id, name, unit, type = AI/DI/STRING），UTF-8 带 BOM |
| `README.md` | 目录说明、约定、重新生成命令 |
| **状态版** `<项目>_状态版/` | `工段 / 设备 / 状态(正常·异常·离线) / 文件`：正常原色、异常整体变红、离线整体变灰且 GLB 无动画；**不带状态灯** |
| `<项目>_设备模型/`、`<项目>_网页视角SVG/` | 不带状态变体的精简版 / 只放页面视角 SVG |

## 二、构建与打包

```bash
node tools/pack/build-pack-<x>.mjs        # 临时起静态服务 + 软件渲染 Chrome 跑导出页，约 1–2 分钟（设备越多越久）
python3 tools/pack/make-zips-<x>.py       # 用 Python zipfile 打 zip（中文文件名带 UTF-8 标志，Windows / macOS 都能正确显示）
```

- **用软件渲染（swiftshader）出图标**：GPU 路径偶发丢上下文，读回全透明 / 贴图变黑。图标读回前检测空白（`hasPixels`）并重画。
- 导出页直接 `import { buildPlant } from '../../js/<name>-plant.js'`，并 `import * as Sim`（点位清单从台账生成）。
- **每个 selectable 一个设备**：标题 → `SLUG`（英文文件名）→ `AREA_OF`（工段名，给状态版分目录）。**新增 / 改名设备要同步 SLUG 和 AREA_OF**，否则文件名是 `asset_N`、工段是“其他”。
- 设备必须是 **plant 里的可选设备**，不要让设备在场景里漂着没有 `sel`（会被当成“平台”导出）：例如泵跟池子分开建时，用 `group.attach(pump)` 并入同组。

## 三、关键实现

- **水面烘焙**：着色器水面 glTF 带不了，导出前按世界 xz 俯视正交渲染成贴图，贴回水面，材质改 `MeshBasicMaterial`（导入后不受光，颜色恒定）；水不会流动。SVG 里水面切成 ~0.3 m 小三角形按贴图逐顶点上色。
- **清理**：去掉管道流动叠加层（`AdditiveBlending`）、把着色器材质换成标准材质；结构件旋转（搅拌桨 / 刮泥桥）导成 glTF 动画（节点名必须唯一，否则动画绑到第一个）。
- **SVG**：`SVGRenderer` 把三维模型投影成多边形，逐面平涂（无渐变），画家算法排序——**大三角面要先按最长边递归切碎**（否则箍带 / 栏杆被罐身盖住）；贴花（带 Logo 的文字）改成按投影仿射贴入的 `<image>`。
- **状态版换色**：保留明暗，把有色部件（蓝泵 / 水面）换成状态色，白灰钢构只染一半，灰色 = 去饱和；水面烘焙贴图逐像素换色；离线版去掉所有动画。
- **点位清单**：台账里每个仪表（AI，位号去空格）、每台泵 / 电机（运行 / 自动 / 故障 DI，变频泵加频率 AI）、电动阀（开启 / 自动 / 故障）、顺序设备（工序 STRING + 压力 AI）、关键工艺量（pH、出水指标、流量、PID 输出、料位三点…）。
- **README 里写清约定**：单位米、Y 向上、右手系、锚点在底面中心、水面是静止贴图、流动动画需自行实现、数值为演示。

## 四、交付检查

- 数量对得上（设备数 / 平台数 / 小件数 / 管线数 / 点位数），随机抽 8 个图标 + 总览图看形态和颜色（介质色是否正确、有没有全透明 / 全黑）。
- zip 大小合理（几十 MB 以内）；状态版目录结构按“工段 / 设备 / 状态”。
- 在回复里列四个压缩包的路径、大小和用途，说明**没有流动动画、数值是演示、报警限不在包里**。
- 之后改了模型要重出：只需重跑两条命令。
